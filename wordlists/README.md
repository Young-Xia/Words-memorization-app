# 四级、六级与雅思 TXT 词表

这六份词表下载自 https://github.com/kajweb/dict ，并转换为 WordsMemory 的导入格式。

- `四级_有道_正序_3739词.txt`：3,739 条。
- `四级_新东方_2607词.txt`：2,607 条。
- `六级_有道_2078词.txt`：2,078 条。
- `六级_新东方_2345词.txt`：2,345 条。
- `雅思_有道_正序_3427词.txt`：3,427 条。
- `雅思_新东方_3575词.txt`：3,575 条。

文件为 UTF-8 编码，每行一条，以制表符分隔 `word`、`meaning`、`frequency`、`senseKey`。中文释义及词性取自原数据；同一词条的多项释义以分号连接。考频、词义编号留空，原数据中的词序不作为考频。

在应用里新建相应词表，选择导入 TXT，再检查预览并确认。不同版本有重叠，建议分别导入不同词表。上述数量是来源词条数，不表示官方大纲数量或各版本互不重复。

`_sources/` 保留下载的原始 ZIP；`sources.json` 记录每份文件的下载链接、条数、独立单词数及 SHA-256。重新下载与转换可在项目根目录运行 `python scripts/download_wordlists.py`。

来源仓库说明数据取自有道背单词，书名与标签沿用来源。这里仅保存为个人学习导入文件，未将这些第三方词库打包为应用内置数据，也不据此声明获得商业再分发授权。
