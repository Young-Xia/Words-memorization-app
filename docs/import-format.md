# 单词导入格式

支持 UTF-8 编码的 TXT、CSV，以及 Word `.docx`。旧版 `.doc` 请先另存为 `.docx`。

字段为 `word`（单词）、`meaning`（释义）、`frequency`（考频）、`senseKey`（词义编号）。除单词外均可留空。表头也支持“单词、释义、考频、词义编号”；有表头时可以调整列顺序，无表头时按以上顺序读取。

- TXT：每行一条，各字段用制表符分隔。只有单词的一列也可导入。
- CSV：用逗号分列。含逗号、换行的字段使用双引号包围，内容里的双引号写两次。
- DOCX：使用普通表格，每行一条、每列一个字段；或每段一条，用制表符分隔字段。表格单元格内的多个段落保留为多行释义。

考频只能是非负整数。空值表示未提供，0 表示明确填写零；不合法的考频会留空并在预览中警告。缺少单词的条目跳过并警告。单词去除首尾空格并转为小写，其余字段去除首尾空格。

解析阶段保留重复条目，不根据相似释义自动合并词义。稳定的词义编号有助于后续更新正确的词义。内容更新与学习进度保存由确认导入后的存储层执行。
