# 词间 · WordsMemory

离线 Windows 背单词应用，使用 Flutter、Drift 和 SQLite。第一版源码包括词表管理、学习卡片、选择题考核、间隔复习、系统通知与完整备份。

## 开发运行

需要 Flutter stable SDK，以及 Visual Studio 的 **Desktop development with C++** 工作负载（含 MSVC、CMake 和 Windows SDK）。VS Code 不能代替这套原生编译工具。

SDK 可放到项目的 `.tools/flutter`，或者配置到 PATH。依赖缓存放在项目 `.tools/pub-cache`。

```powershell
.\scripts\dev.ps1 check
.\scripts\dev.ps1 run
.\scripts\dev.ps1 build
```

若需要直接使用 `cl`、`cmake` 等 C++ 工具，可在终端运行：

```powershell
cmd /k scripts\cpp-env.cmd
```

该脚本自动查找已安装的 Visual Studio C++ 工具链，启用当前终端的 x64 编译环境，并加入本项目的 Flutter SDK。不会修改系统全局 PATH。

发布目录是 `build/windows/x64/runner/Release`，分发时需保留整个目录，而非单独复制 exe。目前提供可构建工程；安装器、签名和正式词库是后续交付项。

Windows 发布版位于 `build/windows/x64/runner/Release`。双击目录内的 `wordsmemory.exe` 即可启动；如需移动应用，请复制整个 `Release` 目录。

## 使用

1. 打开「词表与单词」查看词表目录。点击词表进入单词列表，或在目录里新建、重命名和删除词表。删除词表会保留学习记录。
2. 在具体词表中添加单词，或导入 TXT、CSV、DOCX，检查预览再确认。
3. 背诵时揭晓答案，提交“不认识／模糊／认识”才标记该词义已学。
4. 考核只抽已学词义；未到复习时间的答题属于练习，不增加掌握阶段。
5. 到期检查三次通过：初学约一天后，答对再隔三天，再答对隔七天；第三次通过标记掌握，之后继续抽查。
6. 漏复习不清零。答错退一级并提前复习，当天追加一次错题练习。
7. 设置页导出单个 `.wordsmemory.json` 完整备份；恢复前自动在数据目录生成安全备份。

“需要巩固”的导航与标题书签采用路径绘制，不依赖图标字体；发布脚本保留完整 Material 图标字体，避免裁剪字体缺少新图标。

背诵快捷键：空格揭晓释义，`1` 不认识、`2` 模糊、`3` 认识，左右方向键翻页。揭晓后才能提交自评。考核时按 `1–4` 或 `A–D` 选择并提交，查看结果后按 Enter 或空格继续。输入框与弹窗中不触发学习快捷键；保存期间阻止重复提交。

打开 Num Lock 后，数字小键盘也可用于背诵评分和考核答题。考核提交后可按小键盘 Enter 继续。

“需要巩固”独立页面列出当前考试／词表范围内已学习但尚未掌握的词义，显示巩固阶段、复习时间，并提供“测试此词”和批量巩固测试入口；达到掌握阶段后自动移出。考核与复习首页提供到期复习、已学综合两个入口；巩固练习和逐词测试统一放在“需要巩固”页面。未到期的正确练习不推进阶段；缺少必要语境或可靠选项时不出题。

Windows 中同一登录会话只允许运行一个实例；再次启动会弹窗提示已有程序运行，并退出第二个实例。关闭窗口后进入托盘，托盘菜单可打开或彻底退出。应用运行期间检查到期复习，最多每天提醒一次；不设置开机启动。通知是否显示也受 Windows 通知设置影响。

数据在 `path_provider` 返回的用户应用支持目录内，数据库文件名为 `wordsmemory.db`。备份是明文 JSON，请放在自己信任的位置。

## 数据与词义

内置三套词表共 22 个原创示例词义，用于体验，不是官方考试词库，不包含推测的考试考频。正式考试词表和离线词典需核实授权后再引入。示例中文释义和例句由本项目编写。

同一英文＋规范化后相同释义可关联同一词义；不使用中文相似度自动合并。可通过导入的 `senseKey` 显式关联不同写法的同义释义。词表各自保留自定义释义、考频，词义共用学习进度。改变词义且未提供稳定 `senseKey` 时会新增词义，避免把其他含义的进度错误继承。

导入规范见 [docs/import-format.md](docs/import-format.md)，示例在 `samples/`。没有可信例句的多义词暂不出题。干扰选项采用规范化和别名重叠排除，不承诺自动理解任意中文近义关系；正式扩充词库应维护经过校对的释义与出题数据。

## 工程结构

- `lib/data/store.dart`：SQLite 数据、导入合并和事务备份恢复。
- `lib/services/import_service.dart`：文件解析与警告。
- `lib/domain/review.dart`：复习阶段与调度规则。
- `lib/domain/quiz.dart`：出题范围与选项筛选。
- `lib/ui/home.dart`：词表、卡片、考核、设置界面。
- `lib/services/desktop_service.dart`：系统托盘与通知。
- `test/`：解析、复习、出题、数据库和界面测试。

进度、备份和通知均在本地处理，无账号、服务器或外部 AI 接口。
